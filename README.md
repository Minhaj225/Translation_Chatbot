# Translation Chatbot

A simple notebook-based translation chatbot project.

## Contents

- `chatbot.ipynb`: Main notebook with the chatbot workflow.
- `project_report.docx`: Project report document.

## Usage

1. Open `chatbot.ipynb` in Jupyter Notebook or VS Code.
2. Run the cells from top to bottom.

## Requirements

- Python 3.x
- Jupyter Notebook or VS Code with the Jupyter extension
